# Weather Dashboard

## Overview

A real-time weather dashboard that fetches weather information from the OpenWeatherMap REST API using asynchronous JavaScript.

## Features

* Search weather by city name
* Real-time API requests using Fetch API
* Async/Await implementation
* Comprehensive error handling
* Dynamic DOM updates
* JSON parsing and rendering
* Displays:

  * Temperature
  * Humidity
  * Wind Speed
  * Weather Conditions

## Technologies

* HTML5
* CSS3
* JavaScript (ES6+)
* Fetch API
* OpenWeatherMap REST API

## Learning Objectives Covered

* Asynchronous JavaScript
* RESTful APIs
* Fetch API
* Async/Await
* Error Handling
* JSON Processing
* Dynamic DOM Manipulation

## Setup

1. Obtain a free API key from OpenWeatherMap.
2. Replace `YOUR_API_KEY` in `script.js`.
3. Open `index.html` in your browser.
